هوشیار - نسخه تک‌فایلی
تمام کدهای HTML و CSS و JavaScript داخل index.html قرار دارند.

انتشار در GitHub Pages:
1) ZIP را استخراج کنید.
2) فایل index.html را در ریشه مخزن GitHub آپلود کنید.
3) در Settings > Pages، گزینه Deploy from a branch را انتخاب کنید.
4) شاخه main و پوشه /(root) را انتخاب و Save کنید.

نکته: فونت Vazirmatn از Google Fonts بارگذاری می‌شود و برای دریافت آن اینترنت لازم است.
